# ECDSA Nonce Reuse Educational Tool

## Use the tool

https://katiyar-crypto.github.io/ecdsa-nonce-reuse-tool/

## Highlights

- Polished static UI for ECDSA nonce reuse education.
- Built-in secp256k1 test vector with expected recovered nonce and private key.
- Stronger validation for decimal and `0x` hex inputs.
- Copy buttons for recovered values.
- Exportable recovery report.
- Offline/installable PWA support.
- Desktop and mobile screenshots in the repository.
- GitHub Pages deployment from the `gh-pages` branch.
